# 周刊总览图排版规范

## 用户最新修正：风格锁定，优先于下文旧规则

2026-09-28 用户明确要求：不得改变原风格，只能压缩布局。必须以已下载的 `Benchmark精选周刊_2026-W35_Top9总览(1).png` 为视觉参考：保留浅绿圆角标题框、圆角条目卡片、细绿边框、绿色排名方块、Top 3 淡绿底、深绿字体及底部“本周趋势”框。不得改为直角连续表格，不得取消原有卡片或改变字体配色。旧规则中的“连续九行信息表”“禁止卡片”不再适用。

仅减少卡片内边距、条目间距、标题框和趋势框的空白；卡片高度由文本决定，保持可读字号，优化列宽及英文按词换行。生成时必须附原图作为风格参考，不能仅凭文字猜测。生成前必须从论文或项目原始页面核对每项名称、排名、方向、简介、发布日期和发布机构；任一字段缺失时先完成核对，不得用破折号、占位词或“待补充”生成并交付总览图，也不得编造。

## 构图方向

总览图必须使用竖构图，画布高度大于宽度；建议宽高比约为 0.78–0.85。不得为了竖版而纵向拉伸既有图片，必须重新排列标题、六列信息、九个卡片和趋势框。竖版仍需保持紧凑，九个卡片连续排列，底部趋势框随两行正文自然收紧。

后续每期及重制版必须遵守。用户于 2026-09-28 要求将“紧凑”落实为以下可检查约束。

## 生成提示词

使用最终定稿的 Top 9 数据生成连续九行信息表。字段顺序为：排名 → Benchmark / Dataset → 方向 → 简要介绍 → 发布时间 → 发布机构。项目名下保留作者及完整原始论文链接；没有 arXiv 时使用已核实的原始来源链接。

参考横向画布宽 2400px、外边距 48px；总高度根据内容自然收紧，不预设一个大画布再均分行高。列宽比例参考 4% / 22% / 12% / 38% / 9% / 15%，根据实际文字小幅调整，简介优先。标题、期次和日期区域不超过画布高度的 12%。

表格行高由真实内容决定，单元格顶部对齐，上下内边距 12–18px。禁止大卡片、卡片间空隙、为了等高而撑开的空白行。不要通过缩小正文或删掉重要简介来实现紧凑。正文参考 28–32px，辅助信息保持可读。

英文名称按词或连字符换行，禁止单字母孤行。完整链接使用独立辅助字级，不裁切，不省略；如果放不下，优先调整列宽或画布宽度。中文不因窄列变成逐字竖排。

使用浅绿色表头、细分隔线、克制的深色文字；Top 3 仅在排名或浅色行底上强调。不使用插图、阴影、大装饰标题、渐变或大面积无意义留白。

## 发布前验收

必须实际打开整张成图及原尺寸局部检查，而非仅判断生成命令成功：

- 九条信息完整，与详细文字版的名称、排名、机构、日期及链接一致。
- 没有文字重叠、边界裁切、单字母孤行、丢失或截断链接。
- 正文字号可读，简介空间足够，日期和机构列清楚。
- 行间无大空隙；任何行若存在超过一行文字高度的可消除空白，需要重新排版。
- 底部空白已裁切，表格是视觉主体。

未通过则修改排版并重新导出，不直接交付。保存 PNG 与可编辑源文件。重制时保留旧版备份，使用同一份 finalized 数据，不重新编造或筛选项目。
