# 周刊总览图排版规范

## 最新样式基准（优先于旧版记录）

自 2026-W42 起，以 W42 定稿总览图作为唯一视觉基准：竖版 1600 × 2000 px、浅绿色六列表格、细绿分隔线、深绿文字、Top 3 淡绿行底与底部“本周 Benchmark 变化趋势”框。历史图片重制与后续新图统一由 `scripts/generate-overviews.mjs` 生成，不再使用 W35 的圆角卡片版式。

生成前必须从论文或项目原始页面核对每项名称、排名、方向、简介、发布日期和发布机构；任一字段缺失时先完成核对，不得用破折号、占位词、“未知”或“待补充”生成并交付总览图，也不得编造。

## 构图方向

总览图必须使用竖构图，固定为 1600 × 2000 px。不得为了竖版而纵向拉伸既有图片，必须重新排版标题、六列信息、九行内容和趋势框。竖版仍需保持紧凑，表格连续排列，底部趋势框自然收紧。

后续每期及重制版必须遵守。用户于 2026-09-28 要求将“紧凑”落实为以下可检查约束。

## 生成提示词

使用最终定稿的 Top 9 数据生成连续九行信息表。字段顺序为：排名 → Benchmark / Dataset → 方向 → 简要介绍 → 发布时间 → 发布机构。项目名下保留作者及完整原始论文链接；没有 arXiv 时使用已核实的原始来源链接。

画布宽 1600px、高 2000px、外边距约 42px。列宽比例参考 5% / 21% / 12% / 35% / 9% / 18%，简介优先。标题、期次和日期区域不超过画布高度的 12%。

九行保持统一且紧凑的行高，单元格顶部对齐。禁止大卡片、卡片间空隙和无意义留白。不要通过删掉重要简介实现紧凑；应通过列宽、换行阈值与字号层级解决拥挤。

英文名称按词或连字符换行，禁止单字母孤行。完整链接使用独立辅助字级，不裁切，不省略；如果放不下，优先调整列宽或画布宽度。中文不因窄列变成逐字竖排。

使用浅绿色表头、细分隔线、克制的深色文字；Top 3 仅在排名或浅色行底上强调。不使用插图、阴影、大装饰标题、渐变或大面积无意义留白。

## 发布前验收

必须实际打开整张成图及原尺寸局部检查，而非仅判断生成命令成功：

- 九条信息完整，与详细文字版的名称、排名、机构、日期及链接一致。
- 没有文字重叠、边界裁切、单字母孤行、丢失或截断链接。
- 正文字号可读，简介空间足够，日期和机构列清楚。
- 行间无大空隙；任何行若存在超过一行文字高度的可消除空白，需要重新排版。
- 底部空白已裁切，表格是视觉主体。

未通过则修改排版并重新导出，不直接交付。保存 PNG 与可编辑源文件。重制时保留旧版备份，使用同一份 finalized 数据，不重新编造或筛选项目。
